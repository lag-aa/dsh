# dsh

Каталог настроек DSH Desktop: локальные расширения, которые ставятся в профиль `desktop`.

## Что здесь

| Каталог | Что это |
|---|---|
| [`plugins/dsh-markdown-diff`](plugins/dsh-markdown-diff) | Подсветка git-изменений в правой панели просмотра Markdown: добавленные, удалённые и изменённые блоки, режимы «в тексте» и «рядом», сравнение с `HEAD`, индексом или веткой, замечания к выделению в черновик диалога. Бандл DSH с клиентской и хостовой частями. |
| [`plugins/dsh-notify`](plugins/dsh-notify) | Уведомления DSH Desktop: тост Windows и вебхук на любой HTTP-адрес — о ходе диалога; тихие часы и страница в Настройках. |

## Установка плагина

```
plugin_manager install_bundle
  target: git+https://github.com/lag-aa/dsh.git#<40-символьный коммит>&path:/plugins/dsh-markdown-diff
```

`path:` обязателен: без него установится корень репозитория, а не плагин. В спеке нужен
полный 40-символьный коммит, а не ветка — такую копию можно обновлять
(`plugin_manager` переустанавливает ветку вместо обновления). Для второго плагина меняется
только `path:`:

```
plugin_manager install_bundle
  target: git+https://github.com/lag-aa/dsh.git#<40-символьный коммит>&path:/plugins/dsh-notify
```

Текущий коммит ветки `main`:

```
git ls-remote https://github.com/lag-aa/dsh.git refs/heads/main
```

Локальная копия тоже годится: **Plugins** → **Add plugin** принимает каталог.

## Как добавить своё

- Плагин — каталог `plugins/<имя>` с `package.json`, где объявлен `dsh.bundle.patch`, и
  `files`, включающим `lib/` (собранный бандл) и сам патч: связанный каталог скрывает
  ошибки упаковки, потому что `files` на `link:` не действует.
- Всё остальное — по одной папке на вещь, с README внутри.
- Репозиторий публичный: секреты, строки подключения, выгрузки внутренних систем и рабочие
  имена проектов сюда не попадают.
