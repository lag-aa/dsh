# dsh-markdown-diff

Плагин DSH Desktop: подсветка git-изменений в правой панели просмотра Markdown.

## Ключевые функции

- **Подсветка изменений** — блоки, отличающиеся от базы сравнения, помечаются прямо в
  документе. Сравнение поблочное: абзац, заголовок, элемент списка, блок кода, таблица,
  цитата, линия, кусок HTML.
- **Три режима** — «В тексте» (изменения на своём месте), «Рядом» (две колонки: база слева,
  рабочее дерево справа, ряды выровнены), «Без подсветки» (обычный просмотр).
- **База сравнения** переключается в панели: `HEAD` — все незакоммиченные изменения,
  `Индекс` — только неиндексированные, `Ветка` — выбранная ветка (её верхушка или точка
  ветвления).
- **Комментарии к выделению** — кнопка у выделения открывает поле замечания; «В диалог» или
  `Ctrl+Enter` вставляют в черновик диалога адрес, цитату и замечание. Сочетание настраивается
  и привязано к месту клавиши, поэтому работает в любой раскладке.
- **Настройки** — режим отображения, база сравнения, показывать ли удалённое, сочетание
  клавиш. Те же переключатели есть в панели над документом.

## Цветовая модель

| Что | Как выглядит |
|---|---|
| Блок добавлен | зелёная заливка 26%, зелёная полоса 2 px по левому краю, `+` в жёлобе |
| Блок изменён | зелёная заливка 14%, зелёная полоса 2 px по левому краю |
| Старая половина изменённого блока | сверху, зачёркнута, приглушена (`opacity .7`), отделена пунктиром |
| Блок удалён | красная заливка 12%, красная полоса 2 px, текст зачёркнут |
| Добавленные слова | зелёный фон 26%, зелёное подчёркивание |
| Удалённые слова | красный фон 22%, зачёркивание |
| `±` в жёлобе | правка с общими словами свёрнута в одну рамку |

Когда подсвечены отдельные слова, заливка изменённых блоков ослабляется до 5%: иначе
подсветка слов терялась бы на фоне блока. Цвета берутся из переменных темы DSH
(`state-success-*`, `state-error-*`), поэтому подходят и светлой, и тёмной теме.

## Установка

```
plugin_manager install_bundle
  target: git+https://github.com/lag-aa/dsh.git#main&path:/plugins/dsh-markdown-diff
```

Плагин лежит в репозитории `lag-aa/dsh` каталогом `plugins/dsh-markdown-diff`, поэтому в
спеке есть `path:` — без него установится корень репозитория. `#main` — последняя версия;
копия ставится на момент установки, чтобы обновить — повторите установку.

Локальный каталог тоже годится: **Plugins** → **Add plugin**. Плагин подменяет штатный
просмотр `.md`; вкладку файлов перехватывает только вместе с
[dsh-better-sidebar](https://github.com/omdsh-dev/DSH-better-sidebar) — без него документ
рисуется как рендерер. Подписи интерфейса — русские и китайские.

Подробности устройства, проверки и ограничения — в [README.en.md](README.en.md).
